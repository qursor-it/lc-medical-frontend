Come funziona il reimport

Cancella tutti i pagamenti importati e li ricarica dal file selezionato, nella stessa operazione: alla fine il sistema rispecchia esattamente il file, correzioni e cancellazioni comprese.

Il normale "Invia pagamenti" invece aggiunge soltanto: le righe già presenti vengono saltate, quindi le correzioni di Motiva (importi, mesi di incasso) non verrebbero mai applicate — e una riga con l'importo corretto si sommerebbe a quella vecchia.

È un'operazione tutto-o-niente: se il file non è leggibile non viene cancellato nulla.

Quando usarlo: a ogni invio del Database Unico aggiornato da Motiva. Carica sempre il file cumulativo, non i mensili.
