Impostazioni

Parametri usati per il calcolo automatico delle provvigioni sugli ordini pagati.

Netto = provvigione sull'imponibile. Lordo = provvigione sull'importo IVA inclusa.

Usata solo con base "Lordo", per aggiungere l'IVA all'imponibile dei pagamenti.
